# Тижнева розсилка групи

Щосуботи о 9:00 за Києвом GitHub Actions збирає лист про наступний
тиждень і кладе чернетку в Outlook. Ти її читаєш, правиш і відправляєш.

## Звідки що береться

| Що | Джерело |
|---|---|
| Час, назва і посилання на пару | календар `.ics` |
| Викладач, запасне посилання, «Що зараз» | Notion → Курси |
| Терміни | Notion → Завдання, статус «Відкрито» |
| Можливості | Notion → Можливості, за датами показу |
| Вступний абзац | OpenAI або Anthropic, з фактів вище |
| Стан курсу (пігулка) | обчислюється з дедлайнів |

Модель не бачить ні календаря, ні Notion напряму. Вона отримує вже
зібраний перелік фактів і пише 2–3 речення. Усе інше підставляє код,
дослівно.

## Файли

    zbirka.py        головна збірка: тягне дані, зливає, робить чернетку
    rozklad.py       розбір .ics, розгортання повторюваних подій
    notion_data.py   читання трьох баз через Notion API
    build.py         верстка листа (HTML + текстова версія)
    graph_mail.py    вхід у Microsoft Graph і створення чернетки

## Секрети

Локально — файл `.env` поруч зі скриптами. Скопіюй `.env.pryklad` у
`.env` і заповни; `zbirka.py` прочитає його сам, залежностей не треба.
`.env` уже в `.gitignore`, у git не потрапить.

Змінні оточення мають пріоритет над `.env` — зручно для разових
запусків: `ROZSYLKA=hto@ukma.edu.ua python3 zbirka.py`.

У GitHub Actions ті самі імена задаються через Secrets (ключі) і
Variables (адреси, підпис, дата початку триместру).

## Налаштування

### 1. Реєстрація застосунку

portal.azure.com → Microsoft Entra ID → App registrations → New registration.

- Name: будь-яке
- Supported account types: лише твоя організація
- Redirect URI: не потрібен

Далі в застосунку:

- **Authentication** → Advanced settings → *Allow public client flows* → **Yes**.
  Без цього device code flow не працює.
- **API permissions** → Add → Microsoft Graph → Delegated → `Mail.ReadWrite`.
  Згоди адміністратора цей дозвіл зазвичай не потребує; якщо кнопка
  «Grant admin consent» неактивна — це нормально, достатньо твоєї
  власної згоди під час входу.
- З вкладки **Overview** скопіюй *Application (client) ID*.

### 2. Одноразовий вхід

    export GRAPH_CLIENT_ID=<application-id>
    python3 graph_mail.py --avtoryzatsiya

Відкриваєш посилання, вводиш код, підтверджуєш доступ. Скрипт надрукує
refresh-токен.

### 3. Секрети репозиторію

Settings → Secrets and variables → Actions.

**Secrets:**

| Імʼя | Що це |
|---|---|
| `NOTION_TOKEN` | секрет інтеграції Notion (`ntn_…`) |
| `GRAPH_CLIENT_ID` | Application ID застосунку |
| `GRAPH_REFRESH_TOKEN` | те, що надрукував крок 2 |
| `OPENAI_API_KEY` | для вступного абзацу |
| `ANTHROPIC_API_KEY` | альтернатива OpenAI; якщо задані обидва — виграє OpenAI |
| `GH_PAT` | необовʼязково, див. нижче |

**Variables:**

| Імʼя | Приклад |
|---|---|
| `ROZSYLKA` | адреси через кому |
| `PIDPYS` | Олександр |
| `TRYMESTR_POCHATOK` | `2026-08-31` — понеділок, на який припадає 1 вересня |

### 4. Перевірка

Actions → Тижнева розсилка → Run workflow, поставити «сухий запуск».
Нічого не надішлеться, лист збережеться в артефактах.

## Про refresh-токен

Graph повертає новий токен щоразу. Якщо задати `GH_PAT` з правом
`secrets:write`, воркфлоу сам перезапише секрет, і ланцюжок працює
безкінечно. Без нього токен живе близько 90 днів, після чого треба
повторити крок 2. Перший варіант зручніший, другий — з меншим
радіусом ураження, бо PAT із доступом до секретів сам по собі річ
неприємна. Вибір за тобою.

## Про час запуску

Cron у GitHub Actions працює тільки в UTC, тож воркфлоу стартує о
06:00 і 07:00 UTC, а зайвий запуск сам відсікається перевіркою
київської години. Через це перехід на зимовий час нічого не ламає.

Actions може запізнитися на 5–15 хвилин під навантаженням — для
суботнього ранку це не має значення.

## Що робити, коли лист виглядає дивно

**Пари немає в листі.** Подія в календарі без позначки `[Л]`/`[П]`/`[С]`
у розклад не потрапляє. Або назва не збіглася з жодним курсом — тоді
в логах є рядок «не звʼязалося», а назву треба додати в поле
«Аліаси в календарі».

**Предмет зник із секції «Як справи».** Це навмисно: показуються лише
курси, де заповнене «Що зараз» або є відкритий термін. Порожні рядки
в листі нікому не потрібні.

**Лист без вступного абзацу.** Модель не відповіла. Лист усе одно
зібрався — абзац допишеш сам.
