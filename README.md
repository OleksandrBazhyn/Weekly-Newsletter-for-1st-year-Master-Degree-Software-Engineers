# Тижнева розсилка групи ІПЗ

Збирає тижневий лист для групи магістрів і кладе його чернеткою в
Outlook. Розклад береться з календаря, решта — з Notion, вступний
абзац пише модель. Раз на тиждень запускається автоматично; чернетку
ти читаєш, правиш і відправляєш сам.

## Звідки що береться

| Що в листі | Джерело |
|---|---|
| Час, назва і посилання на пару | календар `.ics` |
| Викладач, запасне посилання, «Що зараз» | Notion → Курси |
| Терміни | Notion → Завдання, статус «Відкрито» |
| Можливості | Notion → Можливості, за датами показу |
| Стан курсу (кольорова пігулка) | обчислюється з дедлайнів |
| Вступний абзац | OpenAI або Anthropic |

Модель не має доступу ні до календаря, ні до Notion. Вона отримує
готовий перелік фактів і пише 2–3 речення. Усі дати, назви й
посилання підставляє код, дослівно.

## Вимоги

- Python 3.11 або новіший (потрібен `tomllib` і `zoneinfo`)
- `python-dateutil` — єдина зовнішня залежність
- Токен інтеграції Notion
- Застосунок у Entra ID із дозволом `Mail.ReadWrite` (лише для
  створення чернетки; переглядати лист можна й без нього)
- Ключ OpenAI або Anthropic (необовʼязково — без нього лист
  збереться без вступного абзацу)

## Встановлення

```bash
git clone <репозиторій> && cd rozsylka
pip install python-dateutil
cp .env.pryklad .env
```

Далі відкрий `.env` і заповни. Мінімум для першого запуску —
`NOTION_TOKEN`.

## Запуск

```bash
# подивитися лист, нічого не надсилаючи
python3 zbirka.py --suho

# конкретний тиждень (аргумент — будь-який день потрібного тижня)
python3 zbirka.py --suho --tyzhden 2026-09-21

# зібрати і покласти чернетку в Outlook
python3 zbirka.py
```

Без `--tyzhden` береться найближчий понеділок, тобто в суботу лист
виходить про наступний тиждень.

Готовий файл зʼявиться в `out/lyst-РРРР-ММ-ДД.html` — відкривай у
браузері. У консоль виводиться зведення: скільки занять, термінів,
предметів і можливостей потрапило в лист.

### Допоміжні команди

```bash
# які назви курсів трапляються в календарі — щоб звірити з аліасами
python3 rozklad.py --nazvy

# розклад тижня у вигляді TOML, без Notion і без пошти
python3 rozklad.py --tyzhden 2026-09-21

# одноразовий вхід у Microsoft, друкує GRAPH_REFRESH_TOKEN
python3 graph_mail.py --avtoryzatsiya
```

## Змінні

Локально — у `.env`, в GitHub Actions — через Secrets і Variables.
Змінні оточення мають пріоритет над файлом:

```bash
ROZSYLKA=hto@ukma.edu.ua python3 zbirka.py
```

| Змінна | Обовʼязкова | Що це |
|---|---|---|
| `NOTION_TOKEN` | так | notion.so/my-integrations → Internal Integration Secret |
| `GRAPH_CLIENT_ID` | для надсилання | Application (client) ID застосунку в Entra ID |
| `GRAPH_REFRESH_TOKEN` | для надсилання | результат `graph_mail.py --avtoryzatsiya` |
| `ROZSYLKA` | для надсилання | адреси через кому |
| `OPENAI_API_KEY` | ні | ключ для вступного абзацу |
| `ANTHROPIC_API_KEY` | ні | альтернатива OpenAI; якщо задані обидва — виграє OpenAI |
| `OPENAI_MODEL` | ні | типово `gpt-5.6-luna` |
| `ANTHROPIC_MODEL` | ні | типово `claude-sonnet-5` |
| `PIDPYS` | ні | підпис у листі |
| `TRYMESTR_POCHATOK` | ні | понеділок першого тижня, типово `2026-08-31` |
| `NOTION_PAGE_URL` | ні | посилання на базу знань у підвалі листа |
| `PS` | ні | рядок наприкінці листа |

`.env` у `.gitignore`. `GRAPH_REFRESH_TOKEN` дає доступ до пошти на
читання й запис — поводься з ним як із паролем.

## Файли

```
zbirka.py        головна збірка: тягне дані, зливає, робить чернетку

```

## Автоматичний запуск

GitHub Actions, щосуботи о 9:00 за Києвом. Cron працює лише в UTC,
тож воркфлоу стартує о 06:00 і 07:00 UTC, а зайвий запуск сам
відсікається перевіркою київської години — перехід на зимовий час
нічого не ламає.

Ручний запуск: Actions → Тижнева розсилка → Run workflow. Там же є
прапорець сухого прогону і поле для конкретного тижня.

Graph повертає новий refresh-токен щоразу. Якщо задати секрет
`GH_PAT` із правом запису секретів, воркфлоу перезапише його сам і
ланцюжок працюватиме безкінечно. Без нього токен живе близько 90 днів,
після чого треба повторити `--avtoryzatsiya`.

## Якщо лист виглядає дивно

**Пари немає в листі.** Подія без позначки `[Л]`/`[П]`/`[С]` у розклад
не потрапляє. Або назва не збіглася з жодним курсом — тоді в логах є
блок «не звʼязалося», а назву треба додати в поле «Аліаси в календарі»
відповідного курсу.

**Предмет зник із секції «Як справи з предметами».** Показуються лише
курси, де заповнене «Що зараз» або є відкритий термін.

**Лист без вступного абзацу.** Модель не відповіла або ключа немає.
Решта листа збирається як завжди.

**Graph відмовив під час надсилання.** Найімовірніше протух
refresh-токен — повтори `--avtoryzatsiya`.
